# Integrações open source candidatas — registro de avaliação

Nenhuma ferramenta abaixo está automaticamente instalada, operacional ou juridicamente liberada por esta atualização. Instalar somente após licença, manutenção, segurança, testes, necessidade e cobertura serem verificados no Tool Registry S0–S10.

| Ferramenta | Finalidade | Ação pendente |
| --- | --- | --- |
| Docling + PyMuPDF | extração de PDFs e tabelas | adapter de ingestão, páginas e qualidade de OCR |
| OCRmyPDF | digitalizados como fallback | isolamento de arquivos e conferência humana |
| Splink | record linkage probabilístico | calibração com dados sintéticos brasileiros |
| OpenRefine | normalização e limpeza | trilha de transformações |
| BGE-M3 + reranker | busca semântica | benchmark em PT-BR e citations/grounding |
| GLiNER Multilingual | NER de contratos | validação de entidades em português |
| DuckDB/Parquet | lake de dados públicos | manifests, versionamento e consultas reprodutíveis |
| Prefect | orquestração e recuperação de falhas | retries, rate-limit, idempotência e autorização |
| OpenLineage | proveniência | lineage de transformações |
| NetworkX/Neo4j | grafos documentados | relações com evidence IDs e revisão |
| Timesketch | timeline | verificação de manutenção/licença |
| FollowTheMoney | modelo de relações e pagamentos | interoperabilidade e critérios de entidade |
| Querido Diário | pesquisa de diários oficiais | origem primária e cobertura de municípios |

Ferramentas de correlação só produzem candidatos e hipóteses, nunca culpa. Prioridade inicial: corrigir hardening, depois OCR e adapters locais, só então IA documental.
