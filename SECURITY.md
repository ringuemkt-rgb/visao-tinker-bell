# Security & Responsible Use

Visão Tinker Bell é destinada a auditoria documental, pesquisa cívica e fontes públicas legítimas.

## Não faça
- não armazene senhas, cookies, tokens ou credenciais em casos/logs;
- não contorne autenticação, paywalls, WAFs ou controles de acesso;
- não use o sistema para vigilância privada, perseguição ou doxxing;
- não infira atributos sensíveis sem necessidade e base legítima;
- não publique acusações automáticas derivadas de scores/red flags.

## Dados pessoais
Aplique necessidade, minimização e finalidade pública. Identificadores só devem ser tratados quando legitimamente públicos e materialmente necessários para resolução de entidade.

## Falhas
Relate vulnerabilidades de forma privada ao mantenedor do repositório. Não inclua dados pessoais reais em provas de conceito.
